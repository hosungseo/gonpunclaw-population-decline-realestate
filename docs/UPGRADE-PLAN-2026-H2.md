# 인구감소지역 부동산 업그레이드 기획안

- 작성일: 2026-08-04
- 대상 저장소: `hosungseo/gonpunclaw-population-decline-realestate`
- 기획 범위: 구현 전 제품·데이터·운영 로드맵

## 1. 한 줄 방향

**한 번 읽는 특례 안내서에서, 107개 정책 대상 지역을 근거와 최신 데이터로 비교하는 지역 탐색기로 확장한다.**

이 제품은 부동산 투자 추천 서비스가 아니다. 인구감소지역·인구감소관심지역의 법적 지위, 적용 가능한 정책, 실제 거래 표본을 한곳에서 확인하도록 돕는 공공형 정보 서비스다.

## 2. 현재 자산

현재 제품은 다음 기반을 갖추고 있다.

- 인구감소지역 89개와 인구감소관심지역 18개, 총 107개 지역 탐색
- 세제, 정주지원, 도시계획, 관심지역 제도 설명
- 최근 24개월 아파트 매매 거래량·중위가격 시계열
- 전국 지도, 시도 필터, 지역 비교표, 지역 상세 패널
- 대표 거래 사례와 표본 수에 따른 해석 경고
- 법령·행정규칙·정책뉴스 출처 연결
- 외부 라이브러리 없는 정적 HTML 기반 GitHub Pages 배포

다음 단계의 핵심은 화면을 더 붙이는 것이 아니라 **자료 자동 갱신, 지역별 고유 주소, 근거 시점, 비교 경험**을 만드는 것이다.

## 3. 목표 사용자와 질문

| 사용자 | 제품에서 해결할 질문 |
| --- | --- |
| 지역 이주·세컨드홈 관심자 | 이 지역은 어떤 지정 유형이며 내 상황에서 확인할 특례는 무엇인가 |
| 지자체 정책 담당자 | 우리 지역과 유사 지역의 거래량·가격 흐름은 어떻게 다른가 |
| 연구자·기자 | 지정 근거, 시행 시점, 데이터 기준일과 원자료는 무엇인가 |
| 지역 사업자·활동가 | 시장 규모뿐 아니라 지역의 생활·정책 여건을 어디서 더 확인할 수 있는가 |

## 4. 업그레이드 원칙

1. **추천보다 근거를 앞에 둔다.** 모든 핵심 수치와 특례에는 기준일과 원출처를 붙인다.
2. **가격만으로 지역을 평가하지 않는다.** 거래 표본, 지정 유형, 생활 맥락을 함께 보여준다.
3. **세제 판단을 대신하지 않는다.** 적용 가능성을 안내하되 개인별 확정 판단은 최신 법령과 전문가 확인으로 연결한다.
4. **정적 배포의 장점을 유지한다.** 가능한 한 사전 생성과 데이터 파일 갱신으로 운영비와 장애 지점을 줄인다.
5. **107개 전 지역을 같은 품질 기준으로 다룬다.** 데이터가 적은 지역은 빈칸을 숨기지 않고 표본 부족을 설명한다.

## 5. 기능 로드맵

### P0 — 최신성·근거·구조 개선

#### 5.1 월별 데이터 갱신 파이프라인

- 국토교통부 실거래가 원자료 수집, 정규화, 집계, 검증을 스크립트로 분리
- 최근 24개월 창을 매월 자동 이동
- 지역별 거래 건수, 중위가격, ㎡당 중위가격, 최근 거래월 산출
- 이전 달 대비 급격한 건수 변화와 누락 지역을 자동 검사
- 검증 통과한 데이터만 GitHub Pages에 반영

완료 기준:

- 수동으로 `index.html`을 수정하지 않고 데이터 파일 교체만으로 갱신
- 107개 지역에 대해 수집 성공, 무거래, 오류 상태가 구분됨
- 사이트에 수집일과 거래 기준기간이 표시됨

#### 5.2 출처 매니페스트

- 지정 고시, 법령, 세제 특례, 거래 데이터마다 `출처 URL`, `시행·기준일`, `수집일`, `버전` 기록
- 종료일이나 유효기간이 있는 제도는 화면에서 별도 경고
- 법령과 고시의 변경 여부를 정기 점검하는 체크리스트 또는 자동 검사 추가
- 숫자와 설명에서 사용한 데이터 파일을 역추적할 수 있게 함

#### 5.3 단일 HTML 구조 분리

- 현재 큰 `index.html`에서 CSS, UI 로직, 데이터 로더를 분리
- 지역 목록·시장 요약·월별 시계열의 스키마를 문서화
- 데이터 검증 테스트와 화면 핵심 흐름 테스트 추가
- 빌드 결과는 계속 정적 파일로 유지

### P1 — 지역 탐색과 비교

#### 5.4 공유 가능한 지역 상세

- 지역마다 고유 주소 제공: 예시 `/region/전남-해남군/`
- 지정 유형, 지정 근거, 적용 시점, 핵심 특례, 시장 요약을 한 화면에 구성
- 그래프와 대표 거래에 데이터 기준일·표본 수를 항상 표시
- 지역 상세 URL을 복사해 보고서나 메신저에서 공유 가능

#### 5.5 2~3개 지역 비교

- 같은 시도, 같은 지정 유형, 거래 규모가 비슷한 지역을 비교 후보로 제안
- 거래량, 중위가격, ㎡당 가격, 최근 거래월, 무거래 월 수를 나란히 표시
- 가격이 아니라 `거래 표본의 두께`를 별도 축으로 보여줌
- 선택한 비교 상태를 URL에 저장

#### 5.6 세컨드홈 확인 순서

- 사용자가 확인해야 할 조건을 질문형 체크리스트로 제공
- 기존 주택 수, 취득 대상 지역, 취득 시점, 공시가격 등 확인 항목을 안내
- 결과는 `가능/불가능 확정`이 아니라 `확인 필요 조항과 공식 문의처`로 제시
- 각 질문에 최신 법령 조항과 시행일 연결

#### 5.7 검색과 탐색 개선

- 지역명 통합 검색
- 지정 유형, 시도, 최근 거래 여부, 거래량 구간 필터
- 지도·표·상세 화면의 선택 상태 동기화
- 모바일에서 지도보다 지역 검색과 결과 요약을 먼저 제공

### P2 — 지역 생활 맥락과 정책 변화

#### 5.8 생활·정책 맥락 연결

- 학교, 의료, 교통, 생활SOC 등 신뢰할 수 있는 공개 지표를 소수만 선별
- 데이터 출처와 갱신주기가 명확한 항목만 제공
- 수치를 단정적으로 평가하지 않고 원자료와 지역 정책 페이지로 연결

#### 5.9 정책 변화 타임라인

- 지역 지정, 관심지역 지정, 주요 특례 시행·변경을 시간순으로 표시
- 법령·고시 변경 시 영향받는 설명과 지역을 식별
- 오래된 설명에는 자동으로 재검토 필요 표시

#### 5.10 다운로드와 인용

- 현재 필터·비교 결과를 CSV로 다운로드
- 지역 상세의 핵심 출처를 인용용 텍스트로 복사
- 연구·보도 활용을 위한 데이터 사전과 이용조건 제공

## 6. PolicyMap 프로젝트와의 연결

두 제품의 역할은 다르지만 지역 코드와 공개 현장정보를 공유할 수 있다.

- 인구감소지역 부동산: 국가 기준의 지정·특례·시장 흐름
- PolicyMap: 지자체가 올린 시설·사업·지역자원 위치

연결 방식:

1. 시군구 코드, 지역명, 지정 유형을 공통 기준 데이터로 관리한다.
2. 지역 상세 화면에 해당 지역의 검증된 공개 PolicyMap 링크를 표시한다.
3. PolicyMap에 인구감소지역·관심지역 레이어를 제공한다.
4. 공개 PolicyMap의 출처·기준일·담당 부서가 확인되는 경우에만 연결한다.

생활시설 데이터를 이 저장소에 복제해 쌓기보다 PolicyMap을 현장 데이터의 발행처로 두는 편이 유지관리와 책임 경계가 명확하다.

- 출처 매니페스트

- ㎡당 가격과 거래 표본 지표
- 검색·필터·모바일 탐색 개선

### 3차 릴리스 — 정책과 생활 맥락을 잇는 사이트

- 정책 변화 타임라인
- 검증된 PolicyMap 연결

## 9. 이번 업그레이드에서 하지 않을 것

- 매물 중개, 시세 예측, 투자 점수 제공
- 개인 상황에 대한 세금 혜택 확정 판정
- 출처와 갱신주기가 불명확한 생활지표 대량 수집
- 데이터가 적은 지역의 가격 추세를 과장하는 순위
- 초기 단계의 사용자 계정·알림 구독 시스템

## 10. 바로 시작할 구현 백로그

1. 현재 JSON 파일의 공통 데이터 스키마와 검증 규칙 작성
2. `source-manifest.json` 설계 및 기존 법령·고시·거래 자료 연결
3. 월별 실거래 수집·집계 스크립트를 재현 가능한 명령으로 정리
4. `index.html`에서 CSS와 JavaScript 분리
5. 한 지역의 정적 상세 페이지를 시범 생성하고 107개 생성 방식 검증
